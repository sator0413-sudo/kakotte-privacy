プライバシーポリシー

Kakotte（カコッテ）

最終更新日：2026年10月6日

Kakotte（以下「本アプリ」）は、読書中に気になった箇所を残しておくための iPad・iPhone アプリです。本アプリは、氏名やメールアドレスなど、利用者個人を識別できる情報を収集しません。アカウント登録も必要ありません。

ただし、購入した状態の確認、広告の効果測定、機能の利用状況の集計のために、一部の情報が外部のサービスへ送られます。詳しくは「5. 購入について」「5-2. 広告の効果測定について」「5-3. 利用状況の集計について」をご覧ください。

1. 収集しない情報

本アプリは、次のいずれも収集しません。

  • 氏名、メールアドレス、電話番号、住所などの個人を識別できる情報
  • 位置情報（端末の位置情報機能は使いません。「5-3」に書いた、IP アドレスから導かれるおおまかな地域を除きます）
  • 連絡先、カレンダー、写真ライブラリの一覧
  • 広告識別子（IDFA）
  • 本の名前、ノート・切り抜き・手書きの中身、メールアドレスなど、利用者個人を識別できる形での利用状況の記録（送られる利用状況は「5-3」に書いた集計用のものだけです）

本アプリに組み込んでいる第三者 SDK は、購入状態の確認（RevenueCat）、広告の効果測定（Meta）、利用状況の集計（Google の Firebase Analytics）の 3 つだけです。利用者を追跡することはありません（App Tracking Transparency の許諾も求めません。そのため広告識別子（IDFA）は取得されず、OS が追跡用の通信を止めます）。

2. 端末の中に保存されるもの

本アプリで作ったものは、すべて利用者の端末の中に保存されます。

  • 取り込んだスクリーンショットと、そこから切り抜いた画像
  • 切り抜きに書き加えた手書き
  • ブックの名前、ページの見出し、お気に入り
  • 読書時間、読んだ日、取り込んだ枚数などの記録

これらの中身が開発者に送られることはありません。開発者はこれらを見ることができません。（機能が使われた回数や読書時間の区分だけは、「5-3」のとおり集計のために送られます。）

3. iCloud へのバックアップ

本アプリは、Apple の iCloud（CloudKit）を使って、利用者のデータを iCloud に控えとして保存します。このとき、データは端末の外（利用者自身の iCloud）へ送られます。

  • 初期状態ではオフです。オフのあいだ、データが端末の外に出ることはありません
  • バックアップはプレミアムの機能で、設定の「iCloud にバックアップする」を

オンにしたときにだけ行われます

  • 保存先は利用者自身の iCloud のプライベートデータベースです
  • 開発者はここにアクセスできません
  • 取り込んだ元のスクリーンショットはバックアップしません（利用者の iCloud の容量を使わないため）
  • 同じ Apple Account の iPad であれば、購読を復元してバックアップをオンにすると、続きから使えます
  • バックアップは本アプリの設定からオフにできます。オフにすると、以後は端末の中だけに保存されます

iCloud の取り扱いについては、Apple のプライバシーポリシーが適用されます。

4. 文字の読み取りと要約は、端末の中だけで行います

  • 文字の読み取り（OCR） — Apple の Vision フレームワークを使い、端末の中だけで処理します
  • 要約の生成 — Apple の Foundation Models を使い、端末の中にあるモデルで処理します

画像や文章が、読み取りや要約のために外部のサーバーへ送られることはありません。

5. 購入について

本アプリの有料の購読（プレミアム）は、Apple の App Store を通じて購入します。支払い情報（クレジットカード番号など）は Apple が扱い、開発者は一切受け取りません。

購入状態の確認には RevenueCat, Inc. のサービスを利用しています。このとき、次の情報が RevenueCat に送られます。

  • App Store が発行する購入レシート
  • 本アプリが生成する匿名の識別子（氏名やメールアドレスとは結び付いていません）
  • 端末ごとの識別子（App ごとに変わるもの。広告用の IDFA ではありません）
  • 端末の種類、OS のバージョン、アプリのバージョン

これらは広告や、他社のアプリ・サイトを横断した追跡には使いません。

RevenueCat の取り扱いについては、同社のプライバシーポリシーをご確認ください。

5-2. 広告の効果測定について

本アプリの広告を Facebook・Instagram に出したとき、その広告からどれだけインストールされたかを知るために、Meta Platforms, Inc. の SDK（Facebook SDK for iOS）を組み込んでいます。このとき、次の情報が Meta に送られます。

  • アプリのインストール・起動、App Store での購入が行われたという記録（本アプリの中で作った切り抜き・書き込み・書名などの中身は送りません）
  • SDK が生成する匿名の識別子（氏名やメールアドレスとは結び付いていません。広告用の IDFA ではありません）
  • 端末の種類、OS のバージョン、アプリのバージョン、言語・タイムゾーンなどの端末の情報
  • アプリが異常終了したときの記録

本アプリは App Tracking Transparency の許諾を求めないため、Meta の SDK は広告識別子（IDFA）を取得せず、利用者を他社のアプリ・サイトを横断して追跡することはありません。広告の効果は、Apple の SKAdNetwork と Meta の集計計測（Aggregated Event Measurement）により、個人を特定しない集計の形で測られます。

Meta の取り扱いについては、同社のプライバシーポリシーをご確認ください。

5-3. 利用状況の集計について

どの機能がどれくらい使われているかを知り、アプリを改善するために、Google LLC の Firebase Analytics（Google Analytics for Firebase）を組み込んでいます。このとき、次の情報が Google に送られます。

  • 機能を使ったという記録と、その種類（例：オンボーディングの完了、切り抜きの保存、ブックの作成、ペンの使用、読書の開始・終了、購入画面の表示、購入の完了）
  • 記録に添える、端末の種類（iPhone か iPad か）、読書時間の区分（5 分未満・5〜30 分・30 分超）、購入した商品の種類（月額か年額か）などの区分の値
  • 購読の開始・更新といった購入の記録（Firebase が App Store の購入情報から自動で測るもので、商品・価格などの情報を含みます。本アプリは支払い情報（カード番号など）を受け取りません）
  • SDK が生成する、アプリごとに変わる匿名の識別子（氏名やメールアドレスとは結び付いていません。広告用の IDFA ではありません）
  • 端末の種類、OS のバージョン、アプリのバージョン、言語・国などの端末の情報、アプリの初回起動・起動回数・利用時間などの自動で測られる記録、通信元の IP アドレスから導かれるおおまかな地域（正確な位置情報は取得しません）

本の名前、ノート・切り抜き・手書きの中身、オファーコードの文字列、メールアドレスは送りません。ユーザー ID も設定しません。広告識別子（IDFA）は使わず、集計した情報を広告や、他社のアプリ・サイトを横断した追跡には使いません。

この集計は、本アプリの「設定」にある「利用状況を送信する」をオフにすると止まります。オフにすると、それ以後は送信されません。

Google の取り扱いについては、同社のプライバシーポリシーをご確認ください。

6. 外部サイトへのリンク

本アプリには、ブックの書名から Amazon.co.jp の検索結果を開く機能があります。このリンクは、利用者がご自身でタップしたときにのみ、標準のブラウザで開きます。本アプリが自動的に外部へ通信することはありません。

このリンクに Amazon アソシエイト（アフィリエイト）のタグが設定されている場合、そのことがアプリの画面上に表示されます。リンク先での行動は Amazon 側の規約とプライバシーポリシーが適用されます。

7. 写真へのアクセス

写真を取り込む機能では、iOS 標準の写真ピッカーを使います。利用者が選んだ画像だけが本アプリに渡ります。本アプリが写真ライブラリ全体を読み取ることはありません。

8. データの削除

  • 端末の中のデータ — 本アプリを削除すると、あわせて削除されます
  • iCloud のバックアップ — 「設定」→ Apple Account → iCloud →「アカウントのストレージを管理」から本アプリのデータを削除できます

9. お子様の利用について

本アプリは 13 歳未満のお子様を対象としていません。お子様から個人情報を意図的に収集することはありません。

10. このポリシーの変更

内容を変更した場合は、このページの「最終更新日」を更新します。重要な変更があるときは、アプリ内でお知らせします。
